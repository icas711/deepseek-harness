# Журнал эволюции скиллов

Единый журнал циклов dsh-skill-evolution по всем скиллам — каждая строка: дата, инцидент (с именем целевого скилла), правка, вердикт критика. Откаты помечаются «откат». Стартовая версия скилла не является циклом эволюции, журнал заполняется с первого цикла.
