# Agent Note: Протокол эволюции скиллов

Status: implemented

## Problem

Скиллы в `.agents/skills` — статичные инструкции. Расхождение шага инструкции с реальным окружением (пути, версии, платформа) каждый раз обходится заново и теряется — накопить опыт внутри скилла было некуда, а проверять качество таких записей было нечем. Правки «по общим соображениям» без внешнего сигнала качества деградируют скилл — исполнитель, оценивающий себя сам, накапливает уверенность, а не точность.

## Decision

Скилл [`dsh-skill-evolution`](../../../skills/dsh-skill-evolution/SKILL.md) проводит цикл эволюции любого скилла каталога — наблюдаемый инцидент, однострочный урок, независимый критик-подагент, минимальная правка, строка в `evolution-log.md` каталога скилла. Уроки живут в разделе «Уроки» SKILL.md целевого скилла (бюджет 15 строк, вытесненные — в `references/experience-archive.md`), потому что загрузчик отдаёт исполнителю только тело SKILL.md — урок в отдельном файле до исполнителя не доходит. Критик — подагент со свежим контекстом, он проверяет, что урок следует из инцидента, правка минимальна, текст соответствует `dsh-prose-standard`. Откат — `git revert` плюс пометка в журнале, все правки идут обычными коммитами через обычное ревью.

С периодическим сопровождением [dsh-code-review по человеческому ревью слитых PR](../../proposed/process/2026-07-13-human-review-skill-maintenance.md) пересечение частичное, обе записи остаются активными — тот процесс владеет источником доказательств «принятое человеческое ревью» и периодическим графиком для одного скилла, этот скилл владеет событийным циклом по инциденту для любого скилла внутри сессии.

## Alternatives considered

- **Плагин с инструментом журналирования опыта в `packages/`.** Отклонено — цикл не требует кода, у агента уже есть edit, subagent и git; плагин добавил бы формат данных, тесты и гейты, не удаляя ручной цикл. Вернуться, если журналы станут структурными данными для загрузчика скиллов.
- **Уроки в отдельном файле рядом со SKILL.md.** Отклонено — загрузчик скиллов отдаёт тело только из SKILL.md, уроки не доходили бы до исполнителя и не меняли поведение; во внешний файл выносятся только вытесненные из бюджета уроки.
- **Правка скилла исполнителем без критика.** Отклонено — единственный источник качества в цикле это внешний вердикт; без него правки сходятся к объёму, а не к точности, что и есть главный риск самоулучшения.
- **Массовый аудит всех скиллов по расписанию.** Отклонено — триггером служит инцидент, явная просьба или переполнение бюджета, расписание создаёт поток правок без доказательной базы; периодический процесс существует только для dsh-code-review и опирается на человеческое ревью.

## Consequences

- Скиллы накапливают окруженческий опыт без изменения загрузчика и продуктового кода, стоимость цикла — один подагент и один коммит.
- Качество зависит от честной фиксации инцидентов — замалчивание обходного манёвра останавливает самоулучшение; автоматического обнаружения «скилл следовало бы улучшить» нет, это известный пробел покрытия.
- Раздел «Уроки» увеличивает каждый запуск скилла на строки уроков, бюджет 15 строк ограничивает эту цену.
