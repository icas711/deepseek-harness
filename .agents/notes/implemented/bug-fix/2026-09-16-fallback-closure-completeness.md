# Agent Note: Неполное замыкание установки — громкий отказ вместо молчаливого сжатия fallback

Status: implemented

## Problem

Хилер `healProfilesModuleFallback` молча пропускал declared-but-unresolved зависимости по контракту «declared-but-uninstalled — не вали boot». Цена скипа проявилась в день релиза realpath-фикса: два запуска сразу после установки упали с `ERR_MODULE_NOT_FOUND` по всем двадцати подключаемым плагинам. Свежее дерево (установщик дописывает файлы, антивирус делает первый проход) на моменты обхода делало часть `package.json` нечитаемой, fallback незаметно сжимался, и нарушение инварианта всплывало далеко от причины — в фазе импортов загрузчика, одной ошибкой на каждый плагин вместо одного диагноза.

## Decision

Полнота замыкания — контракт самого хилера. Обход собирает declared-but-unresolved имена вместе с заявившим их пакетом; легальное отсутствие одно — опциональный peer (`peerDependenciesMeta.*.optional`), pnpm их не автоустанавливает. Неполный проход повторяется после паузы (2 обхода, 2 с между ними; на здоровом дереве второй не запускается), и оставшееся неполным замыкание роняет boot одной ошибкой со списком имён и заявителей вместо стены ошибок загрузчика. Короткая гонка самолечится вторым обходом внутри того же запуска; длинная (установке осталось десятки минут) даёт человеку точный диагноз и действие — перезапустить позже.

## Alternatives considered

- **Прогрев из установщика (постинсталл-запуск хилера)** — дублирует обход в третьем месте, бьётся с той же гонкой и не владеет инвариантом: перенос установки и обновление поверх работающего экземпляра лечатся только при загрузке («moved installations are re-pointed»).
- **Ретрай в `dsh-web.ps1` по тексту лога** — эвристика в лаунчере, маскирующая диагностику: realpath-баг из [installer-fallback-realpath-heal](2026-09-13-installer-fallback-realpath-heal.md) такой ретрай спрятал бы, а не выявил; к тому же чинит только ярлык Windows, а не headless/ACP/dev-запуски.
- **Отказаться от fallback и резолвить имена прямо из установки** — ломает двуханкерный контракт профилей: baseUrl должен оставаться папкой профиля ради out-of-tree плагинов.

## Consequences

Недописанная или битая установка падает на старте с одним сообщением и списком имён, а не двадцатью стеками; здоровое дерево не платит ничего — второй обход не запускается. Контракт «declared-but-uninstalled — скип» из [installer-fallback-realpath-heal](2026-09-13-installer-fallback-realpath-heal.md) заменён; realpath-обход та нота продолжает описывать. Тесты фиксируют: неполный проход догоняется вторым, устойчивая неполнота роняет с именами и заявителями, опциональный peer не мешает, имя, найденное другим заявителем в том же проходе, покидает список.
