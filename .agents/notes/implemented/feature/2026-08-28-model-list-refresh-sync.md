# Agent Note: «Обновить список» — синхронизация каталога моделей с endpoint

Status: implemented

## Problem

Действие «Получить доступные модели» в карточке провайдера умеет только добавлять: уже числящиеся модели приходят в диалог снятыми, и снять галочку с существующей строки нельзя — применить удаление нечем. Каталог нельзя привести к виду «что endpoint сейчас отдаёт» одним действием: убрать переставшие обслуживаться модели приходится построчно руками. Владелец форка ведёт каталог zai-провайдера (GLM-модели) и хочет приводить его к фактическому списку endpoint, выбирая из возможного.

## Decision

`ModelListEditor` получил второе действие — «Обновить список» (`refreshModels`), рядом с получением. Обе кнопки делят одну недоступность (`askable`, `probeBlocked`, занятость) и подпись «Запрос к провайдеру…» меняется только на нажатой. Диалог обновления строится из того же ответа `llm.discoverModels`: все модели endpoint предотмечены, а строки каталога, которых ответ не назвал, показаны ниже снятыми с пометкой «нет у провайдера — будет удалена»; строка без id — черновик — в диалог не входит и переживает применение. Выбор есть итоговый состав каталога: отмеченные существующие строки остаются как настроены и в своём порядке (правки ёмкостей выигрывают у чисел провайдера), отмеченные новые присоединяются в порядке endpoint, снятые исчезают. Пустой ответ по-прежнему отказ `fetchEmpty`, а не диалог: «обновиться до пустоты» почти всегда ошибка конфигурации, а не намерение. Wire-слой не менялся.

## Alternatives considered

**Переделать существующую кнопку вместо второй.** Проигрывает: добавление без удаления — безопасный жест «принеси новое»; смена его семантики сделала бы каждое существующее использование деструктивным (снятая галочка начала бы удалять строки).

**Применять синхронизацию сразу, без диалога.** Меньше кликов, но удаления прошли бы молча; выбор из списка возможных — явная часть запрошенного смысла.

**Не показывать отсутствующие модели, удалять молча.** Пользователь не видит, что уходит, и не может спасти строку галочкой.

**Предотмечать только новые модели, как в добавлении.** Применение тогда удалило бы все существующие строки endpoint — деструктивное умолчание.

## Consequences

Каталог приводится к ответу endpoint одним действием при сохранении ручных правок выживших строк; черновик без id сохраняется, но карточка по-прежнему требует id перед сохранением. По языковой политике форка новые строки интерфейса добавлены в `en` (источник ключей) и `ru`; в `zh`-словаре новые ключи несут русский текст — паритет ключей enforced типами, а нового китайского текста политика не создаёт. Существующий диалог добавления не изменился; заметка-владелец поверхности ([declaring a provider from the Models page](../architecture/2026-08-04-declaring-a-provider-from-the-models-page.md)) перекрёстно ссылается сюда.

## Testing

Снапшот собранного GUI (`apps/web/tests/snapshots/models-settings/declared-edit.expected.md`) фиксирует новую кнопку в карточке.
