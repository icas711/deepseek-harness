# Инструкция по запуску Web-версии DeepSeek Harness

## Требования к системе

- **Node.js**: `^22.19.0` или `>=24.0.0`
- **pnpm**: (только при запуске из исходников) `11.7.0+`

Проверить версию Node.js:
```bash
node --version
```

---

## Способ 1: Запуск через npm (рекомендуется)

### Windows (workaround для ошибки "dsh не является командой")

На Windows команда `npx @deepseek-ai/dsh web` может не работать из-за особенностей обработки аргументов. Используйте один из следующих вариантов:

**Вариант A — с флагом `--yes`:**
```cmd
npx --yes @deepseek-ai/dsh web
```

**Вариант B — через `npm exec`:**
```cmd
npm exec -y @deepseek-ai/dsh web
```

### Linux/macOS
```bash
npx @deepseek-ai/dsh web
```

После запуска сервер будет доступен по адресу: **http://127.0.0.1:3080**

---

## Способ 2: Запуск из исходников

Если вы клонировали репозиторий и хотите запустить web-версию из исходного кода:

```bash
# 1. Установить зависимости
pnpm install

# 2. Собрать проект
pnpm run build

# 3. Запустить web-версию
pnpm dsh web
```

Или одной командой:
```bash
pnpm install && pnpm run build && pnpm dsh web
```

---

## Изменение порта и хоста

По умолчанию сервер запускается на `127.0.0.1:3080`. Чтобы изменить параметры:

```bash
# Другой порт
npx --yes @deepseek-ai/dsh web --port 8080

# Другой хост (внимание: только 127.0.0.1 или 0.0.0.0)
npx --yes @deepseek-ai/dsh web --host 127.0.0.1 --port 9000
```

> **Примечание:** Привязка к `0.0.0.0` намеренно не поддерживается из соображений безопасности.

---

## Основные причины ошибки "dsh не является командой"

### 1. Неправильная команда на Windows
На Windows нужно использовать `npx --yes` или `npm exec -y` вместо простого `npx`.

### 2. Пакет не установлен в текущем проекте
Если вы работаете в локальной копии репозитория, команда `pnpm dsh` работает только после успешной сборки (`pnpm run build`).

### 3. Node.js неподходящей версии
Проверьте, что версия Node.js соответствует требованиям (`^22.19.0` или `>=24.0.0`).

### 4. Повреждённая установка npm-кеша
Попробуйте очистить кэш:
```cmd
npm cache clean --force
```

## Дополнительная информация

- После запуска в терминале будет выведена строка вида: `dsh web: http://127.0.0.1:3080`
- Web UI позволяет работать с DeepSeek Harness через браузер
- Для разработки с горячей перезагрузкой можно использовать `pnpm run dev:web` (требует исходников)
