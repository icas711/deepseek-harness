# @deepseek-ai/dsh-tool-fleet

Model-facing Consumer службы флота (`ctx.fleet`): пять инструментов жизненного цикла worktree-фанлаута. Загрузка плагина требует смонтированных `ctx.tools` и `ctx.fleet`; вызывающий без owning-сессии отвергается.

## Инструменты

- `fleet_fanout(repo_path, count, prompt, base_ref?)` — запускает N параллельных попыток в изолированных worktree; относительный `repo_path` резолвится от cwd сессии владельца; возвращает id фанлаута и членские сессии.
- `fleet_status(fanout_id?)` — снимки фанлаутов вызывающего с live-состоянием попыток (`starting`/`running`/`idle`/`gone`).
- `fleet_diff(fanout_id)` — stat и унифицированный diff каждой попытки против общей базы (изменения трекаемых файлов плюс untracked-файлы строками `(untracked) <path>` в stat); diff обрезается до `maxDiffBytes` (UTF-8-граница кодпоинта, с маркером).
- `fleet_merge(fanout_id, session_id)` — слияние ветки победителя; работающая попытка и конфликт отвергаются с объяснением.
- `fleet_cleanup(fanout_id)` — остановка попыток, удаление worktree и веток, дерегистрация workspace.

Все карточки — `generic`: результаты не содержат готового к рендеру diff-представления. Дисциплина работы (не плодить фанлауты для тривиальных задач, собирать статусы перед финальным ответом, сливать ровно одного победителя, затем чистить) зафиксирована в описаниях инструментов.

## Конфигурация

| ключ | значение по умолчанию | смысл |
|---|---|---|
| `maxDiffBytes` | `16384` | потолок diff-текста одной попытки в `fleet_diff`. |

## Model Experience

### Схемы инструментов (tool schemas)

#### What the model sees

Сгенерированные схемы `fleet_fanout`, `fleet_status`, `fleet_diff`, `fleet_merge`, `fleet_cleanup` из [каталога инструментов](../../../docs/tool-catalog.md#deepseek-aidsh-tool-fleet), пока набор видим.

#### Token effect

Фиксированная стоимость схем на каждый запрос, где инструменты видимы.

#### KV Cache effect

Префикс стабилен, пока определения и видимость инструментов не меняются; жизненный цикл регистрации может инвалилидировать с первой изменённой схемы.

### Results and completion notices

#### What the model sees

`fleet_fanout` возвращает id фанлаута и member-строки (`sessionId`, `branch`, `worktreePath`); `fleet_diff` — stat/diff с маркером обрезки; уведомление о завершении попытки — одно сообщение `fleet <id>: attempt <session> finished …` в сессию владельца.

#### Token effect

Результаты остаются в истории родителя до компакции; обрезка `maxDiffBytes` ограничивает каждый полный diff.

#### KV Cache effect

Только добавление: новый контент идёт после переиспользуемого префикса запроса.

## Known Limitations and Deferred Work

- Отдельная prompt-секция не регистрируется: дисциплина живёт в описаниях инструментов; выделенная секция появится, если снимки покажут её необходимость.
- Строки результатов на английском (model-facing текст закреплён снапшотами); русская локализация UI — вне model-facing поверхности.
