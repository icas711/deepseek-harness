# @deepseek-ai/dsh-fleet

Служба оркестрации worktree-фанлаута (`ctx.fleet`): один промпт → N параллельных попыток, каждая — обычная сессия верхнего уровня в собственном git worktree базового репозитория. Членские сессии регистрируются как workspace и видны во всех существующих поверхностях (Web GUI, браузер телефона, персистентность) без нового UI. Дизайн и отвергнутые альтернативы — в [заметке о фанлауте](../../../.agents/notes/implemented/feature/2026-10-11-worktree-fanout-fleet.md).

## Сервис: `Fleet` (ключ ctx: `fleet`)

- `fanout(request, owner)` — создаёт N worktree (`dsh-fleet/<short>/<i>` от базового sha), регистрирует workspace, запускает членского агента (`ctx.agents.create`, `cwd` = worktree, `delegationDepth` = глубина владельца + 1, маршрут provider/model — текущая выборка `agentDefaultModel.currentSelection()`, тот же источник, что у create/resume хоста) и доставляет промпт через `agent.followup()`. Частичный провал откатывает уже созданные попытки (агенты + worktree). Владелец — единственный разрешённый вызывающий всех глаголов (owner-fence по `SessionId`, как в job registry).
- `status(caller, fanoutId?)` — снимки фанлаутов вызывающего, новых-first; состояние попытки выводится из реестра агентов (`starting` не наблюдается после создания, `running`/`idle` по `agent.status`, `gone` — агента нет).
- `diff(caller, fanoutId)` — diff каждой попытки против базового sha через `ctx.worktrees.diff`.
- `merge(caller, fanoutId, sessionId)` — слияние ветки победителя в текущий HEAD базового репозитория; работающая попытка отвергается, конфликт откатывается и возвращается классификацией.
- `cleanup(caller, fanoutId)` — остановка членских агентов, удаление worktree и веток, дерегистрация workspace; персистентные сессии попыток остаются.

Уведомление: первый `turn/end` попытки доставляет владельцу одно сообщение (занятому — `inject`, свободному — `followup`), зеркально дорожкам доставки job-completion.

Время жизни: служба владеет хэндлами членских агентов; выгрузка композиции останавливает их. Worktree остаются на диске как долговечные артефакты попыток.

## Конфигурация

| ключ | значение по умолчанию | смысл |
|---|---|---|
| `maxMembers` | `5` | максимум попыток одного фанлаута. |
| `maxFanoutDepth` | `2` | потолок `delegationDepth`, с которого ещё разрешён вложенный фанлаут. |

Оба лимита живут и в settings-секции `fleet`: при смонтированном settings-провайдере служба регистрирует пространство имён с composition-конфигом в качестве базового слоя, значения читаются перед каждым `fanout()` (изменение применяется к следующим фанлаутам без перезапуска), а отсоединение провайдера возвращает composition-конфиг. Web GUI редактирует секцию строкой «Флот» в настройках «Общие» ([dsh-client-ui-fleet-settings](../../client/ui-fleet-settings/README.md)); по проводу секция открыта адресно в allowlist apiproxy.

## Model Experience

### Fleet fanout service

#### What the model sees

Косвенно, через [`dsh-tool-fleet`](../tool-fleet/README.md): служба не регистрирует собственных схем и промптов; инструменты возвращают id фанлаута и членских сессий, а уведомление о завершении попытки приходит сообщением в сессию владельца.

#### Token effect

Сама по себе — нулевой; токены порождают только инструменты `fleet_*` и уведомление о завершении (одно короткое сообщение на попытку).

#### KV Cache effect

Независима: фанлаут не меняет префикс запроса владельца; новые сообщения присоединяются после переиспользуемого префикса.

## Known Limitations and Deferred Work

- Записи фанлаута процесс-локальны: после перезапуска host worktree, workspace и персистентные сессии попыток остаются, но связь «фанлаут → попытки» теряется; долговечное состояние (storage domain) отложено.
- Пресет членского агента не выбирается: попытки работают на хост-композиции; параметр `agentPreset` появится вместе с ростером пресетов во флоте.
- Автовозобновление членских агентов после перезапуска отсутствует: сессии попыток возобновляются вручную из GUI.
- Уведомление о завершении — только первый `turn/end` попытки; последующие ходы пользователя в членской сессии владельца не будят.
