# @deepseek-ai/dsh-station-connector

Коннектор станции — маленькое Node-приложение для машины пользователя. Сам dial-out'ится по WSS к оркестратору (работает за NAT, ничего не пробрасывается), аутентифицируется токеном станции и исполняет операции моста: fs через node:fs, процессы через node:child_process.

## CLI

```sh
dsh-station pair --server https://cloud.example.com --code ABCD2345 [--name «ноутбук»] [--root D:\Работа]
dsh-station run [--server wss://…] [--home D:\.dsh-station]
```

- `pair` запрашивает у хоста приветствие сопряжением, получает токен (едет по проводу ровно один раз) и пишет config.json в домашней папке коннектора: `$DSH_STATION_HOME` или `~/.dsh-station`. Права файла 0600, папки 0700; на Windows POSIX-права не действуют — это сказано в выводе.
- `run` читает конфиг, подключается по токену и обслуживает операции до Ctrl+C. Разрывы лечатся переподключением с экспоненциальным бэкоффом (1 с → 30 с, джиттер ±20%); отказ хоста (`bad-token`, `protocol-version`, `bad-code`) — постоянный: повтор бессмыслен, нужно повторное сопряжение.
- При остановке и разрыве коннектор завершает все запущенные им процессы (POSIX — SIGTERM/SIGKILL по группе, Windows — `taskkill /T /F`).

Корень мира исполнения фиксирован конфигом; каждый путь (fs-операции и cwd процессов) проходит двойную проверку изоляции — лексическое удержание и канонизацию realpath — общим кодом протокола. Хост проверяет путь до отправки, коннектор — перед исполнением: его корень и есть реальность.

## Model Experience

None, as the package is a user-machine daemon executing capability operations; nothing here reaches a model request.

#### KV Cache effect

None; this package neither assembles nor sends a provider request.

## Known Limitations and Deferred Work

- **Событий вывода без backpressure** — коннектор шлёт stdout/stderr по мере поступления; буферизация на сокете ограничена лишь окном TCP, лимиты собираемого вывода применяет хост-провайдер.
- **`inherit`-потоки уходят в консоль станции** — диагностика ребёнка видна на машине пользователя, а не в сессии хоста.
- **Установщики и автозапуск — этап 6**: пакет распространяется как workspace-пакет, самостоятельной сборки бинарников под Windows/macOS ещё нет.
- **Привязка задач и офлайн-очередь хоста — этап 5b**: коннектор просто переподключается; хост пока не ставит операции в очередь офлайн-станции.
